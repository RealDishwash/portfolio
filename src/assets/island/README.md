# Island artwork

The terrain, foliage, rocks, flowers, and sign are adapted from Kenney's
[Nature Kit](https://kenney.nl/assets/nature-kit). The house and location buildings are from
[City Kit (Suburban)](https://kenney.nl/assets/city-kit-suburban), and the
sky elements are from
[Background Elements Remastered](https://kenney.nl/assets/background-elements-remastered).

All three packs are released under Creative Commons CC0 1.0. The PNG files in
this directory were losslessly trimmed to remove transparent padding.

The location names are used descriptively in an unofficial fan-made interface.
No extracted or data-mined Nintendo game files are included.
